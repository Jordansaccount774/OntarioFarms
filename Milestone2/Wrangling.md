 Statistics Canada's datasets included extra metadata, irregular formatting, and symbols tied to values posed a significant obstacle to the data wrangling process. Before the dataset could be used in Excel, descriptive rows above the actual data in many of the tables had to be eliminated. Furthermore, a number of values contained letters like "A" or "B," which denoted data quality and needed to be cleaned in order for the numbers to be correctly examined. Making sure that all datasets were uniformly filtered to just contain Ontario and similar years presented another challenge. Before any analysis or visualization could be done, it was required to standardize column names, eliminate unnecessary data, and convert values to numeric formats.
